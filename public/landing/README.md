# Imágenes de la landing (opcional)

La página de inicio usa URLs de Unsplash como respaldo. Para usar fotos propias, guarda estos archivos aquí:

| Archivo | Uso | Tamaño sugerido |
|---------|-----|-----------------|
| `hero.jpg` | Banner principal (restaurante / ambiente) | **1920×1080** px, JPG &lt; 500 KB |
| `mapa-pedidos.jpg` | Sección clientes (delivery / app) | **1200×800** px |
| `pos-cocina.jpg` | Sección comercios (cocina / POS) | **1200×800** px |

Formato: JPG o WebP. Nombres exactos como en la tabla.

Tras agregarlas, reinicia el servidor de desarrollo si no se ven de inmediato.
